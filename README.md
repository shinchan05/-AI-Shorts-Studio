# AI Shorts Studio (Windows starter)

A free-first local app for creating original narrated vertical Shorts from a topic. It generates a starter script and scene prompts, can use images generated by ComfyUI, creates AI narration, burns captions into scenes, adds subtle zoom motion, and exports MP4 with FFmpeg.

## Important limitation
This first version produces a narrated, motion-enhanced slideshow from AI-generated images. It does **not** yet create true AI-generated moving footage. To get true video scenes, install a compatible ComfyUI video model/workflow and add a model-specific video workflow adapter in a later version. Hardware requirements vary greatly by model.

## Requirements
- Windows 10/11
- Python 3.11 recommended
- FFmpeg installed and available in PATH
- NVIDIA GPU is helpful for ComfyUI generation, but the app can also use uploaded images.
- Internet required for `edge-tts` narration and installing Python packages.

## Setup in PowerShell
Open PowerShell in this extracted folder:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Add your existing FFmpeg folder for this terminal session (based on the path previously shared):
```powershell
$env:Path += ";C:\Users\reddy\OneDrive\Desktop\ffmpeg-9.0.2-essentials_build\bin"
```
Check:
```powershell
ffmpeg -version
```

Launch:
```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```
Open the local URL Streamlit prints (usually http://localhost:8501).

## Use without ComfyUI
1. Open **Script & prompts** and enter your topic.
2. Edit the narration and scene prompts.
3. Open **Generate visuals** → **Upload images**.
4. Upload 3–8 images you made yourself or generated with an image model, one per scene.
5. Open **Export MP4** → **Generate narration + export MP4**.
6. Download the MP4. Exports are also saved in `outputs/`.

## Optional: connect ComfyUI for local image generation
1. Install ComfyUI using its official installation instructions: https://docs.comfy.org/installation/desktop
2. Start ComfyUI and confirm the UI opens at `http://127.0.0.1:8188`.
3. In ComfyUI, load a compatible **image-generation** workflow.
4. Use **Save (API Format)** to export the workflow JSON.
5. Put the JSON at `workflow_api.json` in this project, or browse to it in the app.
6. Find the positive prompt node ID in that JSON (the node whose inputs contain `text`, `prompt`, or `positive`) and enter that ID in the app.
7. Click **Generate scene images with ComfyUI**.

The exact workflow and node ID depend on the model/workflow you install. This generic integration cannot safely guess them. If ComfyUI is running on another port, change the URL in the app.

## Troubleshooting
- `ffmpeg not found`: add the FFmpeg `bin` directory to PATH and restart Streamlit from that PowerShell.
- TTS error: check internet connectivity; `edge-tts` uses an online speech service and may change.
- ComfyUI API error: verify `http://127.0.0.1:8188` is running and the API workflow JSON is valid.
- CUDA out-of-memory: choose a smaller model, lower image resolution/batch size, or use image uploads.

## Next upgrade for true AI video
A real text-to-video workflow is model-specific. We need the exact NVIDIA GPU model and VRAM (Task Manager → Performance → GPU) before choosing a suitable ComfyUI video model. Many high-quality models will not fit on entry-level GPUs.
